# Homework 3 - Bakery Website

## Project Description

For this assignment, I created a five-page bakery website. The website is a dynamic site that injects the different page views into the index page instead of loading a new HTML page for each section.

The website was created using the MVC model that we have been using in class. I also used SCSS to organize and style the different pages of the website.

## Pages

The website includes five pages:

- Home
- About
- Services
- Contact
- FAQ

Each page contains text and images related to the bakery.

## Features

- Five different page views
- Dynamic page content
- Navigation using the URL
- MVC structure
- Images and text on every page
- SCSS used for styling
- Separate SCSS file for each page
- Organized project folders

## Technologies Used

- HTML
- JavaScript
- jQuery
- SCSS
- CSS
- MVC
